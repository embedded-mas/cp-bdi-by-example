# 1. Application overview
This application example illustrates an two cooperating robots.

# 2. Application Scenario
This application contains two turtle agents (see the agent code [here](src/agt/sample_agent.asl)) which coordinate their moving around the environment: one robot waits while the other one is moving.
# 3. Requirements
- Java JRE >= 21
- [Docker](https://www.docker.com/)

# 4. Running the example
Launch the first robot: `./gradlew turtle1`
Launch the second robot: `./gradlew turtle2`
